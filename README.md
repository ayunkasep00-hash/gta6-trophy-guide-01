An offline, open-source guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a full guide in our own words with sources, a checklist saved in the browser, export and import, filters by kind, a spoiler setting that hides story trophies until earned, a roadmap to the platinum, and missable trophies flagged.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open app/index.html directly in desktop Chrome with the network off; the app is fully static and works offline.
